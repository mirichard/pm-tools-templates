## Explainability, missing inputs, ties, and sensitivity

No #1161 scoring rules are approved. If the owner selects a calculation aid, its method-definition work should explicitly settle these items before implementation:

1. **Taxonomy and input contract:** identify each field's meaning, source, allowed values/units, applicability, assessment horizon/date, accountable assessor, and rationale/evidence. Map fields only after source verification; do not assume the paper's model inputs are a reusable taxonomy.
2. **Missing/stale/uncertain evidence:** distinguish unknown, not applicable, stale, and not assessed. Missing probability, impact, response-effect evidence, or dependency evidence must not silently become zero/low, isolated, or an assumed mitigation reduction. State whether a score is unavailable and identify the missing inputs.
3. **Risk state:** keep inherent, current assessed residual, and hypothetical post-response views separate. Distinguish planned, implemented, and verified response effects. Do not equate an ordinal score change with money saved or real-world mitigation effectiveness.
4. **Rules and explanation:** publish rule/specification version, inputs and evidence, intermediate calculation, factor meanings, thresholds, rounding, overrides and override rationale, output class, and reason. A fixed specification and input set must yield the same result; deterministic arithmetic does not remove judgment from inputs or rule design.
5. **Ties and ordering:** define whether equal scores share rank and what, if anything, breaks a display-order tie. Keep the underlying component judgments visible so equal products do not erase different risk profiles. Do not invent a severity order from ID or wording without policy.
6. **Sensitivity and boundaries:** define and test monotonic changes only where the approved method promises them; test threshold boundaries, extreme values, rounding and modifier interactions. If a method is non-monotonic by design, explain why. No threshold, default, modifier, normalization, confidence rule, stale-data limit, or override is selected by this report.
