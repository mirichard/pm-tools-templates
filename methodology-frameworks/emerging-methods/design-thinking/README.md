# Design Thinking Integration Templates

This directory contains templates that integrate design thinking methodology with traditional project management practices. These templates help teams apply human-centered design principles to project planning and execution.

## Templates Overview

| Template | Purpose | Use Case |
|----------|---------|----------|
| [Design Thinking Workshop](design-thinking-workshop-template.md) | Facilitate design thinking sessions | Workshop planning and execution |
| [Empathy Map Template](empathy-map-template.md) | Understand user perspectives | User research and persona development |
| [Ideation Framework](ideation-framework-template.md) | Generate and evaluate ideas | Creative problem solving |
| [Prototype Planning](prototype-planning-template.md) | Plan prototyping activities | MVP and proof-of-concept development |
| [Innovation Project Charter](innovation-project-charter-template.md) | Charter innovation projects | Project initiation with design thinking approach |

## Integration with Agile

These templates are designed to integrate seamlessly with agile user story development and sprint planning. The design thinking process feeds into traditional project management phases:

- **Empathize & Define** → Requirements gathering and user story creation
- **Ideate** → Solution design and feature prioritization
- **Prototype** → Sprint planning and MVP development
- **Test** → User acceptance testing and iteration planning

## Methodology Alignment

- **PMBOK Process Groups**: Primarily supports Initiating and Planning process groups
- **Agile Framework**: Compatible with Scrum, Kanban, and SAFe methodologies
- **Innovation Management**: Supports organizational innovation frameworks

## Getting Started

1. Start with the [Innovation Project Charter](innovation-project-charter-template.md) for new innovation projects
2. Use the [Design Thinking Workshop](design-thinking-workshop-template.md) to facilitate team sessions
3. Apply the [Empathy Map Template](empathy-map-template.md) for user research
4. Generate solutions using the [Ideation Framework](ideation-framework-template.md)
5. Plan implementation with the [Prototype Planning](prototype-planning-template.md) template

## Best Practices

- Involve diverse stakeholders in design thinking sessions
- Balance creativity with practical constraints
- Document insights and decisions for future reference
- Iterate based on user feedback and testing results
- Integrate findings into traditional project management artifacts
