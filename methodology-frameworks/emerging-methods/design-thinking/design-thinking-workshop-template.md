# Design Thinking Workshop Template

## Workshop Overview

**Purpose**: Facilitate a structured design thinking session to solve complex problems and generate innovative solutions

**Duration**: 4-8 hours (can be split across multiple sessions)

**Participants**: 6-12 diverse stakeholders including end users, domain experts, and implementation team

## Pre-Workshop Preparation

### Workshop Setup
- [ ] **Define Challenge Statement**: Clear problem statement to focus the workshop
- [ ] **Assemble Diverse Team**: Include users, stakeholders, and subject matter experts
- [ ] **Prepare Materials**: Post-it notes, markers, flipchart paper, timer
- [ ] **Book Space**: Large room with wall space for posting materials
- [ ] **Set Expectations**: Share agenda and desired outcomes with participants

### Background Research
- [ ] Gather existing user research and data
- [ ] Prepare user personas (if available)
- [ ] Review current state documentation
- [ ] Identify key constraints and assumptions

## Workshop Agenda

### Phase 1: Empathize (60-90 minutes)

**Objective**: Understand the user perspective and build empathy

#### Activities:
1. **User Story Sharing** (20 minutes)
   - Participants share real user experiences
   - Focus on emotions, frustrations, and motivations
   - Record insights on empathy map

2. **Stakeholder Journey Mapping** (30 minutes)
   - Map current user journey/process
   - Identify pain points and moments of delight
   - Note assumptions that need validation

3. **Perspective Taking** (30 minutes)
   - Role-play different user scenarios
   - Consider diverse user types and edge cases
   - Document emotional journey

#### Deliverables:
- [ ] Completed empathy map
- [ ] User journey map with pain points identified
- [ ] List of assumptions to validate

### Phase 2: Define (45-60 minutes)

**Objective**: Synthesize observations into a clear problem statement

#### Activities:
1. **Insight Synthesis** (20 minutes)
   - Group similar observations
   - Identify patterns and themes
   - Prioritize most critical insights

2. **Problem Statement Creation** (25 minutes)
   - Craft "How Might We..." statements
   - Ensure statements are human-centered
   - Select 2-3 statements to focus on

#### Deliverables:
- [ ] Prioritized insight themes
- [ ] 2-3 focused "How Might We" statements
- [ ] Refined challenge statement

### Phase 3: Ideate (60-90 minutes)

**Objective**: Generate a wide range of creative solutions

#### Activities:
1. **Divergent Thinking** (30 minutes)
   - Brainstorm solutions for each "How Might We" statement
   - Encourage wild ideas, build on others' ideas
   - Defer judgment, strive for quantity

2. **Idea Clustering** (20 minutes)
   - Group similar ideas
   - Identify themes and patterns
   - Name each cluster

3. **Convergent Thinking** (30 minutes)
   - Evaluate ideas against criteria (feasibility, desirability, viability)
   - Dot voting for initial prioritization
   - Select top 3-5 ideas for prototyping

#### Deliverables:
- [ ] Comprehensive list of ideas (aim for 50+)
- [ ] Clustered and themed ideas
- [ ] Top 3-5 prioritized solutions

### Phase 4: Prototype (45-60 minutes)

**Objective**: Create low-fidelity prototypes to test key assumptions

#### Activities:
1. **Prototype Planning** (15 minutes)
   - Define what to prototype for each selected idea
   - Identify key assumptions to test
   - Assign teams to each prototype

2. **Rapid Prototyping** (30 minutes)
   - Create low-fidelity prototypes (sketches, storyboards, mock-ups)
   - Focus on core functionality/experience
   - Keep it simple and testable

#### Deliverables:
- [ ] 3-5 low-fidelity prototypes
- [ ] List of assumptions each prototype tests
- [ ] Basic testing plan for each prototype

### Phase 5: Test & Plan Next Steps (30-45 minutes)

**Objective**: Gather feedback and plan implementation

#### Activities:
1. **Prototype Sharing** (20 minutes)
   - Teams present prototypes to group
   - Gather initial feedback
   - Identify strengths and concerns

2. **Next Steps Planning** (15 minutes)
   - Define user testing approach
   - Assign ownership for next actions
   - Set follow-up meeting

#### Deliverables:
- [ ] Feedback summary for each prototype
- [ ] User testing plan
- [ ] Action items with owners and timelines

## Post-Workshop Actions

### Immediate (Within 1 week)
- [ ] Document all outputs and insights
- [ ] Share workshop summary with participants
- [ ] Plan user testing sessions for top prototypes
- [ ] Update project documentation with insights

### Short-term (Within 1 month)
- [ ] Conduct user testing
- [ ] Refine prototypes based on feedback
- [ ] Develop implementation roadmap
- [ ] Integrate findings into project charter/backlog

### Long-term (Ongoing)
- [ ] Monitor implementation progress
- [ ] Gather user feedback continuously
- [ ] Iterate based on learnings
- [ ] Document lessons learned

## Success Criteria

- [ ] Clear problem definition established
- [ ] Multiple solution options identified
- [ ] Testable prototypes created
- [ ] Next steps defined with owners
- [ ] Participant engagement and satisfaction high
- [ ] Insights integrated into project planning

## Workshop Facilitation Tips

1. **Keep Energy High**: Use energizers, vary activities, take breaks
2. **Encourage Participation**: Ensure all voices are heard
3. **Manage Time**: Use timers, keep activities moving
4. **Document Everything**: Capture all ideas and insights
5. **Stay User-Focused**: Return to user needs when discussions drift
6. **Embrace Ambiguity**: Comfort with uncertainty is key
7. **Build on Ideas**: Encourage "Yes, and..." mindset
