# Startup Project Kit

## Overview
This starter kit reuses maintained Lean Startup templates that already exist in the repository. It is designed for founders and product teams who need a clear path from business assumptions to customer evidence without creating a separate kit-specific template set.

## Quick Start Sequence

1. Capture business assumptions in the [Lean Canvas Template](../../methodology-frameworks/emerging-methods/lean-startup/lean-canvas-template.md).
2. Convert assumptions into testable statements with the [Hypothesis-Driven Planning Template](../../methodology-frameworks/emerging-methods/lean-startup/hypothesis-driven-planning.md).
3. Define smallest releasable scope and learning goals in the [MVP Planning Template](../../methodology-frameworks/emerging-methods/lean-startup/mvp-planning-template.md).
4. Set metrics, pass/fail thresholds, and controls with the [Experiment Design Template](../../methodology-frameworks/emerging-methods/lean-startup/experiment-design-template.md).
5. Run interviews and evidence review via the [Customer Validation Framework](../../methodology-frameworks/emerging-methods/lean-startup/customer-validation-framework.md).
6. Operate iterative loops with the [Build-Measure-Learn Cycle Template](../../methodology-frameworks/emerging-methods/lean-startup/build-measure-learn-cycle.md) and make structured direction changes with the [Pivot Decision Framework](../../methodology-frameworks/emerging-methods/lean-startup/pivot-decision-framework.md).

## Expected Outputs

- A one-page model with explicit risk assumptions (Lean Canvas)
- Prioritized and testable hypotheses with success criteria
- MVP scope boundaries tied to learning objectives
- Experiment design with metrics and decision thresholds
- Customer evidence summary that supports continue/pivot decisions
