# Team performance domain

Use this domain to build, lead, develop, and sustain the people doing the project work.

## Scope and boundary

Team includes formation, roles, skills, ceremonies, collaboration, feedback, conflict resolution, and knowledge transfer. External engagement belongs in [Stakeholder](../stakeholder/); methodology and work execution belong in [Delivery](../delivery/); portfolio-level resource allocation belongs in [Planning](../planning/).
