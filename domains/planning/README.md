# Planning performance domain

Use this domain to establish project strategy, scope, schedule, budget, and resource approach.

## Scope and boundary

Planning covers business cases, charters, scope, schedules, budgets, resources, procurement, and strategic alignment. Iteration-level planning belongs in [Delivery](../delivery/); risk response belongs in [Uncertainty](../uncertainty/); ongoing reporting belongs in [Measurement](../measurement/).
