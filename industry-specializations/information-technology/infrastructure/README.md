# IT Infrastructure Templates

## Purpose and overview

Use this directory to find maintained planning resources for this practice area. Select a template below, review its usage guidance, and adapt a working copy to the needs of your project. These links preserve access from templates that have moved to domain-based locations.

## Usage instructions

Start with the linked template that matches your planning activity. Confirm ownership, assumptions, and review dates before using its output for a delivery decision. Follow any canonical-location link shown by a legacy file to reach the maintained resource. This directory guide supports navigation; the linked files contain the actual template instructions and working sections.
