## Use a template

1. **Choose a template.** Read its purpose and guidance to confirm it fits your project. New to project management? Follow the [getting started guide](docs/getting-started/README.md).
2. **Make a working copy.** For Markdown (`.md`) templates, open **Raw** and copy the text into your editor, or download the raw file. For other formats, download the file and open it in compatible software.
3. **Adapt it.** Replace example content and placeholders, retain the sections you need, and agree on ownership and review frequency with your team.

You can use individual templates without installing the repository. To get the whole collection, [download the repository ZIP](https://github.com/mirichard/pm-tools-templates/archive/refs/heads/main.zip). File formats vary; a Markdown template is not automatically a Word, Excel, or PowerPoint file.
