## How Bundles Work

Each bundle includes:
- **Essential templates** — Start with these, they're non-negotiable
- **Recommended templates** — Add these as your project matures
- **Optional supplements** — Industry or risk-specific additions
- **Complementary resources** — Toolkits, guides, and assessments
- **What's NOT covered** — Explicit scope boundaries
- **Next steps** — Clear actions to get started

Bundles reference templates — they don't duplicate them. All links point to the actual template files in this repository.
