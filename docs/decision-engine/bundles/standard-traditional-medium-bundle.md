# Standard Traditional Bundle (Medium Project)

**For:** Experienced PMs on standard waterfall projects
**Methodology:** Traditional
**Scale:** Medium (10–50 people, 3–12 months)
**Risk Level:** Medium
**Rules Trace:** R001, R005, R008, R017, R021, R024

## What This Bundle Does NOT Cover

- **Program management** — Single-project scope only. For multi-project programs, see [Enterprise Governance Bundle](enterprise-governance-bundle.md).
- **Executive dashboards** — Add from [Business Stakeholder Suite](../../../business-stakeholder-suite/) if executive reporting is needed.
- **Industry compliance** — Add industry templates based on your domain.

## Next Steps

1. **Complete the Project Management Plan** — This is your master reference document
2. **Build the WBS** — Decompose scope into manageable work packages
3. **Create the schedule** — Sequence activities and assign durations
4. **Initialize risk and budget tracking** — Set baselines before execution begins
5. **Establish change control** — Use the Change Request template for all scope changes
